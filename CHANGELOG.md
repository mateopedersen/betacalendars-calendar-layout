# Changelog

## 0.1.1 — 2026-10-07

- Add offline month, year, blank-grid, paper, compare, validation, and version CLI commands.
- Add Fedora RPM packaging for runtime, development, and documentation subpackages.
- Expand the 1900–2100 materialized-grid checks and CLI smoke tests.
- Add generated 2027 and 2026–2027 boundary fixtures.

## 0.1.0 — 2026-10-07

- Initial C++17 header-only release.
- Gregorian civil-date weekday and month topology for years 1–9999.
- Seven week starts, natural and fixed grids, adjacent-date policies.
- Undated grid and printable geometry metrics for common paper formats.
- CMake package export, optional CLI, and exhaustive calendar tests.
